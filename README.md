# 워크로그

팀 업무를 한 목록에서 등록하고, 상태와 마감일로 나눠 보는 웹 서비스다.

## 팀

풀스택빌런즈

| 이름 | 역할 |
| --- | --- |
| 유신 | 팀장. 기획, 저장소, 통합, 배포 |
| 김승태 | 업무 화면과 API 연결 |
| 장하준 | 공통 화면과 반응형 |
| 김리온 | 서버, 데이터베이스, API |

## 목표

해야 할 일을 등록하고, 진행 상태를 바꾸며, 마감이 가까운 일부터 볼 수 있게 한다.

## 최소 기능

- 업무 목록 조회
- 업무 등록, 수정, 삭제
- 상태 변경, 상태 필터
- 검색, 우선순위, 마감일
- 규칙 기반 추천

## 저장소

기능 개발은 `develop`에서 분기한다. `main`은 발표와 배포에 쓰는 브랜치다.

실행 방법은 3–4일차에 서버와 화면 뼈대를 만든 뒤 이 문서에 추가한다.
