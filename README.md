# 시드픽

풀스택빌런즈. 스타트업을 보고 가상 자금으로 사고파는 앱.

## 실행

MongoDB가 `localhost:27017`에 떠 있어야 한다. 데이터베이스 이름은 `seedpick`이다. 다른 주소를 쓰려면 `.env.example`을 `.env`로 복사하고 `MONGODB_URI`를 바꾼다.

```
npm install
npm run dev
```

화면은 http://localhost:5173

## 시연

1. 목록에서 이름, 지역, 소개로 검색하고 업종을 고른다.
2. 추천 카드를 눌러 상세로 간다.
3. 수량을 넣고 매수한다.
4. 포트폴리오에서 매도한다.
5. 주문 내역에서 주가와 금액을 확인한다.

회고는 [docs/회고.md](docs/회고.md)
