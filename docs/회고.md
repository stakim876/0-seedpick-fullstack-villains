# 회고

시연 순서는 목록, 검색, 추천, 매수, 포트폴리오 매도, 주문 내역이다. 새로고침 후에도 잔액과 내역이 남는다.

## 잘한 점

- 목록, 상세, 포트폴리오, 주문 내역을 나누고 담당을 정했다.
- 매수와 매도 계산은 서버가 하고, 화면은 그 결과만 다시 그린다.

## 문제점

- MongoDB가 꺼지면 계좌를 불러올 때까지 목록이 나오지 않는다.
- 8–10일 확장은 검색, 추천, 등락 색, 수량 검사라 하루에 비해 양이 작다.
- 배포 주소가 없다.

## 개선점

- 계좌를 못 불러와도 목록은 보여 준다.
- 서버와 화면을 올려 README에 주소를 적는다.
