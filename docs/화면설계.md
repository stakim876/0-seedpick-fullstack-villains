# 화면 설계

업무 네 화면으로 이동한다. 공통 상단에는 서비스 이름과 목록, 등록 링크를 둔다.

## 사용자 흐름

1. 목록에서 상태와 검색어로 업무를 좁힌다.
2. 등록 화면에서 제목, 설명, 우선순위, 마감일을 넣고 저장한다.
3. 상세 화면에서 내용을 수정하거나 상태를 바꾼다.
4. 삭제를 누르면 확인 후 목록으로 돌아간다.
5. 목록 상단의 추천 영역에서 마감이 가깝거나 우선순위가 높은 업무를 연다.

## 목록

- 상태 필터: 전체, 할 일, 진행 중, 완료
- 검색 입력
- 업무 카드: 제목, 상태, 우선순위, 마감일
- 추천 업무 3개
- 등록 버튼
- 결과가 없을 때 안내 문구

김승태가 조회와 필터 동작을 연결하고, 장하준이 카드와 필터 배치를 맞춘다.

## 등록

- 제목 필수
- 설명
- 우선순위: 낮음, 보통, 높음
- 마감일
- 저장, 취소
- 제목이 비어 있으면 저장하지 않고 안내한다

## 상세 · 수정

- 저장된 내용을 보여 준다
- 상태 변경: 할 일, 진행 중, 완료
- 수정 저장
- 삭제 확인

## 오류

- 목록을 불러오지 못하면 다시 시도 문구
- 없는 업무 주소는 목록으로 돌아가는 링크
- 저장 실패 메시지를 폼 위에 보여 준다

장하준이 좁은 화면에서 카드가 한 줄로 쌓이게 맞춘다. 11–12일차에 김승태와 함께 확인한다.
