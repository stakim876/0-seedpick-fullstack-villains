# 화면 설계

시드픽은 목록, 상세, 포트폴리오, 주문 내역으로 이동한다. 공통 상단에는 서비스 이름, 목록, 포트폴리오, 주문 내역, 주문 가능 금액이 있다.

## 사용자 흐름

1. 목록에서 이름, 지역, 소개, 업종으로 기업을 좁힌다.
2. 등락률이 높은 기업 3개 중 하나를 눌러 상세로 간다.
3. 상세에서 수량을 넣고 매수한다.
4. 포트폴리오에서 보유를 매도한다.
5. 주문 내역에서 방금 주문을 확인한다.

## 목록

- 검색 칸, 업종 선택
- 추천 3개와 기업 카드
- 불러오는 중, 실패, 다시 시도
- 기업이 없을 때, 검색 결과가 없을 때 문구

## 상세

- 소개, 업종, 단계, 지역, 주가, 등락률
- 보유 수량
- 수량 입력, 매수 금액, 매수
- 없는 기업은 목록으로 돌아가는 링크

## 포트폴리오

- 총 자산, 평가 손익, 주문 가능 금액
- 보유 목록. 이름을 누르면 상세로 이동
- 보유가 없으면 안내
- 매도 기업, 매도 수량

## 주문 내역

- 전체, 매수, 매도
- 시각, 기업 이름, 매수·매도, 수량, 주가, 금액
- 내역이 없거나 필터 결과가 없으면 안내
- 기업 이름을 누르면 상세로 이동

## 오류

- 목록과 상세를 불러오지 못하면 안내
- 수량, 잔액, 보유 수량이 맞지 않으면 주문하지 않고 문구만 보여 준다
- 계좌를 불러오거나 저장하지 못하면 안내

좁은 화면에서는 검색 칸, 카드, 요약 칸이 한 줄로 쌓인다.
