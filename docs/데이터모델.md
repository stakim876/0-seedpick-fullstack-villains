# 데이터 모델

MongoDB 컬렉션 이름은 `tasks`다.

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| title | String | 예 | 제목. 앞뒤 공백 제거, 빈 문자열 불가 |
| description | String | 아니오 | 설명. 없으면 빈 문자열 |
| status | String | 예 | `todo`, `doing`, `done`. 기본값 `todo` |
| priority | String | 예 | `low`, `medium`, `high`. 기본값 `medium` |
| dueDate | Date | 아니오 | 마감일. 없으면 추천 조건에서 마감일로 올라오지 않는다 |
| createdAt | Date | 예 | 생성 시각 |
| updatedAt | Date | 예 | 수정 시각 |

추천은 별도 컬렉션에 저장하지 않는다. 조회할 때 아래 순서로 고른다.

1. `status`가 `done`이 아니다.
2. `priority`가 `high`이거나 `dueDate`가 오늘부터 이틀 이내다.
3. 마감일이 빠른 순, 같으면 우선순위가 높은 순으로 3개.

3–4일차에 김리온이 이 구조로 컬렉션을 연결하고, 샘플 업무 5개를 넣는다.
