# 데이터 모델

데이터베이스 이름은 `seedpick`이다.

## startups

샘플 기업 8개. 시세 기록은 두지 않고, 현재 주가와 등락률만 둔다.

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| id | String | 기업 번호 |
| name | String | 기업 이름 |
| description | String | 소개 |
| industry | String | 업종 |
| stage | String | 단계 |
| region | String | 지역 |
| price | Number | 가상 주가 |
| changeRate | Number | 등락률. 양수는 상승, 음수는 하락 |

## accounts

계좌 문서 하나다.

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| cash | Number | 주문 가능 금액. 처음은 10,000,000 |
| holdings | Array | 보유. 기업 번호, 이름, 수량, 평균 단가, 주가, 평가액 |
| orders | Array | 주문 내역. 기업 번호, 이름, 매수·매도, 수량, 주가, 금액, 시각 |

추천은 별도 컬렉션에 저장하지 않는다. 목록 화면이 등락률이 높은 기업 3개를 고른다.
